# Proposal

## Why

Arcshift needs a clearer roadmap overview, a private operations dashboard, and public recovery and terms pages.

## What Changes

- Present roadmap progress, remaining effort, and phase status in the member workspace.
- Add a read-only operations dashboard behind a verified Google sign-in and one immutable owner identity.
- Serve a branded HTTP 404 page and a public draft Terms and Conditions page.

## Capabilities

### New Capabilities

- `arcshift-dashboards` covers the member overview, private operations, and public pages.

### Modified Capabilities

None.

## Impact

React navigation and dashboard views, Express routes, and Google session metadata.
